# Cart 購物車

> 記錄現有程式的實際行為。改規則時，程式與本文件放在同一支 Pull Request 更新。
> 跨模組的流程見 [模組總覽](README.md)。

購物車只在前端，沒有自己的後端 API（校正時借用商品列表的 `ids` 篩選）。理由見 [CLAUDE.md §5](../../CLAUDE.md#5-認證與狀態)「購物車放前端，不放伺服器」：
狀態放前端，金額的裁決權在後端。

## 用例

| 用例 | 誰 | 畫面 |
|---|---|---|
| 加入購物車 | 訪客、會員 | 商品列表、商品明細、搜尋結果（見 [Products](Products.md)、[Search](Search.md)） |
| 調整數量、移除商品 | 訪客、會員 | `CartView.vue`（`/cart`） |
| 看金額預覽 | 訪客、會員 | `CartView.vue`（`/cart`） |
| 校正現價與庫存 | 訪客、會員 | `CartView.vue`（`/cart`）、`CheckoutView.vue`（`/checkout`）載入時 |
| 前往結帳 | 訪客、會員 | `CartView.vue` 的「前往結帳」→ `/checkout`（見 [Orders](Orders.md)） |

## 業務規則

### 保存

- 存在瀏覽器的 localStorage（鍵 `konbini.cart`），關掉瀏覽器再開還在；不同瀏覽器、不同裝置之間不同步。
- 登入、登出都不影響購物車；未登入也能使用。
- 下單成功後清空。
- 每一列存 `productId`、`name`、`price`、`imageUrl`、`quantity`，沒有版本號。載入時格式不對的列直接丟掉
  （`productId`、`quantity` 不是正整數，`name` 不是字串，`price` 不是數字），其他列照常載入。
- 校正得到的庫存只放在記憶體，不存進 localStorage。

### 品項與數量

- 以商品 Id 合併：同一個商品再加一次，只增加數量，不會多一列。
- 加入時的數量取整數（小數無條件捨去）；結果不是正數（0、負數、空白）就不加入。
- 每項商品的上限是庫存與 99 件（`MAX_ITEM_QUANTITY`，與後端 `OrderItem.MaxQuantity` 對齊）取小的；
  加入後的合計超過上限時調整成上限。購物車頁的「＋」用最近一次校正的庫存，還沒校正過時只看 99 件。下單時後端會再檢查數量與庫存。
- 加入後提示結果（`useAddToCart`）：成功時「已加入購物車」；被庫存限制時「庫存只剩 N 件，購物車已調整為 N 件」；
  被 99 件限制時「每項商品最多 99 件，購物車已調整為 99 件」。
- 每一列存加入當下的商品名稱、單價、圖片，校正時更新成現在的值；下單時一律以後端現價計算。

### 校正

購物車頁與結帳頁載入時，以 `GET /api/products?ids=…&pageSize=100` 取購物車裡每項商品的現價與庫存
（見 [Products「列表」](Products.md#列表)）。結帳送出被拒、錯誤裡有 `items`（400 商品不存在、409 庫存不足）時再校正一次。

| 情況 | 購物車 | 提示 |
|---|---|---|
| 價格不同 | 單價改成現價 | 「{品名}：價格從 NT$ {舊} 改為 NT$ {新}」 |
| 名稱、圖片不同 | 改成現在的值 | 不提示 |
| 數量超過庫存，庫存大於 0 | 數量降到庫存數 | 「{品名}：庫存只剩 N 件，已調整為 N 件」 |
| 售完（庫存 0） | 保留那一列，數量不變，標示「已售完」 | 不另外提示 |
| 查不到（已刪除；之後的下架也是） | 保留那一列，標示「已下架」 | 不另外提示 |
| 連不到伺服器 | 維持原樣 | 「暫時無法確認最新的價格與庫存，送出訂單時會再確認。」 |

- 有提示時在頁面上方列出，標題「購物車已依最新的價格與庫存更新」；下一次校正沒有變動就不再出現。
- 已售完、已下架的列不算進小計與合計；購物車裡有這種列時不能結帳，要先移除。
- 只校正送出請求當下的列：等待回應時新加入的商品不會被當成查不到，被移除的列也不再處理。
- 前端分不出「已刪除」與「已下架」，查不到一律顯示「已下架」。
- 決策與理由見 [DD-CRT-001](decisions/Cart.md#dd-crt-001購物車與現價庫存的校正2026-11-20使用者決定claudemd-6購物車價格與現價不同步)。

### 金額預覽

| 項目 | 計算 |
|---|---|
| 小計 | Σ 單價 × 數量，只算可以購買的列（不含已售完、已下架） |
| 運費 | 小計滿 500 為 0，未滿為 60（`FREE_DELIVERY_THRESHOLD`、`DELIVERY_FEE`，與後端 `Pricing` 對齊） |
| 合計 | 小計＋運費；沒有可以購買的列時為 0 |

## 前端行為

- **購物車頁**：每列顯示商品、單價、數量、小計與「移除」；數量用「－」「＋」調整，減到 0 就移除該列，
  到上限（庫存與 99 取小的）時「＋」停用。已售完、已下架的列在品名旁標示，圖片變淡，小計顯示「—」。
  下方顯示小計、運費（附「（滿 500 免運）」）、合計與「前往結帳」。
  有已售完、已下架的列時，「前往結帳」停用，上方顯示「請先移除已售完或已下架的商品，才能結帳。」
- 購物車是空的時顯示「購物車是空的，去逛逛。」，連到 `/products`。
- 「前往結帳」不檢查登入，由結帳頁處理（見 [Orders](Orders.md)）。
- header 的購物車圖示顯示總件數（所有品項的數量加總）。
- 頂部公告「單筆滿 NT$500 免運費」的金額取自 `FREE_DELIVERY_THRESHOLD`；購物車頁的「（滿 500 免運）」是寫死的文字。
